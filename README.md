# dot-files

- `.tmux.conf`, `.emacs`, `.gitconfig`, `.gitignore` + `setup.sh`: arquivos antigos, genéricos (symlinks via `setup.sh`).
- [`omarchy/`](omarchy/README.md): tudo que difere do padrão na instalação Omarchy (Hyprland, tmux, git/ssh, mise, emacs) e um `bootstrap.sh` idempotente para refazer. No Omarchy use só o bootstrap, não o `setup.sh`.
